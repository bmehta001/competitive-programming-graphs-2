Practice shortest paths with negative edge weights in a cursed dungeon full of traps, boost shrines, and one-way portals.

| 1 | Bellman-Ford: Cursed Dungeon Routes | 20 | Negative weights, relaxation, negative-cycle detection |

GitHub Classroom autograding runs the Java question. Python and C++ versions are included for local practice or instructor-directed use.

Bellman-Ford is the right tool when paths may include negative edge weights. In this assignment, a negative edge is a helpful boost or magic shortcut; a reachable negative cycle is an infinite boost loop where no finite best path exists.
